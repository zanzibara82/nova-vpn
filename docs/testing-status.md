# Статус проверок NovaVPN

Правило чтения: механизм называется проверенным только если его строка стоит в таблице
«проверено» с командой прогона. Всё остальное — «not-run», и полагаться на это нельзя.
Файл обновляется вместе с кодом, который меняет покрытие: когда механизм появляется в
коде раньше, чем в прогоне, он приходит сюда строкой в «not-run», а не молчанием.

Первый живой прогон новой фазы `lifecycle` упал на измерении: 43 строки `ok`, затем

Причина — разрешение имени, а не туннель. У форвардера стенда (`dnsmasq`) для

адрес. Громкий отказ при пустом ответе обязателен: тихий возврат к имени вернул бы
ровно тот дефект, который маскировался. Ограничение стенда (нет AAAA, поэтому
AAAA-ветка разрешения не проверена) остаётся открытым и перенесено в `not-run`.
