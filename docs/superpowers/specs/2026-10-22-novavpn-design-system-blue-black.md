# NovaVPN Design System — сине-чёрный (blue-black)

**Дата:** 2026-10-22. **Статус:** черновик на ревью заказчику (до утверждения не является контрактом для циклов C/E).

**Цель:** единый визуальный язык NovaVPN — палитра двух тем, токены, типографика и базовые компоненты, из которых цикл C (React-панель) и цикл E (клиенты) собирают интерфейсы, не переизобретая цвета и правила.

**Утверждённое направление (решения заказчика 2026-10-22):**

1. Дизайн-система как фундамент (а не отдельные макеты поверхностей).
2. Характер — премиальный тёмный: почти чёрные поверхности с холодным синим подтоном, сдержанный синий акцент, много воздуха.
3. Две темы: тёмная по умолчанию + светлая; одна структура, разные значения.
4. Поставка — этот документ + HTML-витрина `design/showcase.html` (обе темы живьём).
5. Типографика — Inter (основной) + JetBrains Mono (технический текст).

## 1. Принципы

- **Не чистый чёрный.** Поверхности несут синий подтон (`#0A0E1A`-семейство) — чёрный без подтона выглядит мёртвым на OLED и «недоделанным» на IPS.
- **Один акцент.** Синий появляется только там, где сообщает факт: интерактив, выбор, состояние «подключено». Никакого декоративного синего, градиентов и свечения ради свечения.
- **Контраст посчитан, не обещан.** Все пары §7 прогнаны скриптом `.scratch/contrast_audit.py`; текст ≥ 4.5:1, границы контролов ≥ 3:1 (WCAG AA). Новые цвета — только через дополнение этого спека и пересчёт §7.
- **Честный язык.** Интерфейс не обещает того, чего продукт не делает; статусы только фактические (см. §6).
- **Тёмная — по умолчанию.** Светлая — та же семантика, другие значения; компоненты не знают, в какой теме живут.

## 2. Механика тем

- Все цвета — CSS-переменные с префиксом `--nv-` на `:root`.
- Тема задаётся атрибутом `data-theme="dark" | "light"` на `<html>`; значения в `:root[data-theme="dark"]` и `:root[data-theme="light"]`.
- Компоненты ссылаются только на семантические токены (`var(--nv-text-1)`); сырые hex допустимы лишь в блоке определения токенов.
- Переключение не перезагружает страницу и не дублирует компоненты.

Правила употребления:

- `--nv-accent` не используется как фон кнопки; для этого есть `--nv-accent-strong`.
- Белый текст допустим только на `--nv-accent-strong`.
- `--nv-border` — только декоративные линии; всё, что пользователь должен распознать как контрол, очерчивается `--nv-input-border`.
- Статусные цвета в бейджах — текст статус-цвета на мягком фоне: бленд цвета статуса с поверхностью `--nv-surface-1` на 12 %.

## 4. Типографика

- **Inter** (400/500/600/700) — весь интерфейс; подключение Google Fonts с `display=swap`, fallback `Segoe UI, system-ui, sans-serif`. Шрифт несёт латиницу и кириллицу.
- **JetBrains Mono** (400/500) — ключи WireGuard, отпечатки, IP-адреса, идентификаторы, журналы; fallback `Consolas, monospace`.

Шкала:

| Роль | Размер/интерлиньяж | Вес | Применение |
| --- | --- | --- | --- |
| display | 28/36 | 600 | крупные числа и заголовки экранов |
| title-1 | 20/28 | 600 | заголовки карточек, страниц |
| title-2 | 17/24 | 600 | заголовки секций, диалогов |
| body | 15/23 | 400 | основной текст |
| body-strong | 15/23 | 600 | ключевые значения, имена |
| small | 13/18 | 400 | вторичный текст, подписи |
| mono | 13/20 | 400 | ключи, адреса, идентификаторы |

- Числовые колонки и метрики — `font-variant-numeric: tabular-nums` (цифры не «прыгают» при смене значений).
- Micro-label (надзаголовок секции): 11px, uppercase, `letter-spacing: .08em`, `--nv-text-muted`.
- Язык интерфейса по умолчанию — русский (решение проекта от 2026-10-22); пара Inter+JetBrains Mono покрывает кириллицу и латиницу (ключи, адреса, идентификаторы).

## 5. Пространство, радиусы, тени, фокус

- Сетка отступов 4px: 4 / 8 / 12 / 16 / 24 / 32 / 48.
- Радиусы: `s` 6px (контролы), `m` 10px (карточки), `l` 14px (диалоги); `999px` (бейджи, свитчи).
- Тени — тёмная тема: карточка `0 1px 2px rgba(0,0,0,.4)`, диалог `0 8px 24px rgba(0,0,0,.5)`. Светлая: `0 1px 2px rgba(19,26,41,.06)`, диалог `0 8px 24px rgba(19,26,41,.12)`. Никаких цветных свечений у обычных элементов.
- Фокус — только `:focus-visible`: кольцо 2px `--nv-accent` с отступом 2px от контрола. Дефолтные outline переопределяются, не удаляются.

## 6. Базовые компоненты

Копирайтинг общий для всех компонентов: активный залог («Save changes», не «Submit»); одно действие — одно имя во всём потоке («Publish» → тост «Published»); ошибки объясняют, что случилось и что делать, без извинений; пустое состояние — приглашение к действию. Числовые метрики без реального замера не отображаются вовсе; демо-данные в макетах помечаются «Sample data».

- **Button.** Варианты: `primary` (accent-strong + белый), `secondary` (surface-2, text-1, hairline border), `ghost` (прозрачный, text-accent), `danger` (danger-strong-вариант: danger как текст и граница на прозрачном). Размеры: `m` 36px, `s` 28px. Отключённая — text-muted на surface-2, без акцента. Кнопка называет действие, а не сущность.
- **Input.** Высота 36px; тёмная тема — фон surface-2, светлая — surface-1; граница `--nv-input-border`; фокус — кольцо из §5. Label над полем — small/text-2. Ошибка — граница danger + сообщение danger под полем. Select и поиск — тот же каркас.
- **Checkbox / Switch.** Отметка и включённый свитч — `--nv-accent-strong`; выключенный свитч — поверхность + `--nv-input-border`. Состояние «вкл» дублируется не только цветом, но и позицией/галочкой (не полагаться на цвет).
- **Badge.** Статусные: точка + текст статус-цвета на мягком 12%-фоне, pill. Словарь: `Connected`, `Connecting`, `Disconnected`, `Active`, `Expiring`, `Error` — только факты, без эпитетов. Чипы выбора — accent-soft + accent.
- **Card.** surface-1, radius-m, hairline border, внутренние отступы 16–24px; заголовок title-2, действия — ghost-кнопки справа.
- **Table.** Шапка small/text-muted; строки body/text-2; ключи и адреса — mono с переносом по символам; статусы — бейджи; числовые колонки — tabular-nums; hover строки — surface-2. Если минимальная ширина колонок больше карточки — таблица скроллится горизонтально внутри карточки (`overflow-x: auto`).
- **Dialog.** surface-1, radius-l, тень диалога; заголовок title-2; подтверждающая кнопка primary, отмена — secondary, справа; разрушительное действие — danger-вариант.
- **Toast.** surface-2, radius-m, тень; цветная точка статуса слева; короткий текст активным залогом («Settings saved»).

### Сигнатура — «кольцо связи» (link ring)

Единственный запоминающийся элемент системы, общий для всех поверхностей: кольцо 2px с разрывом 60°, метафора туннеля.

- Отключено: `--nv-text-muted`, без свечения.
- Подключение: `--nv-accent`, плавное вращение (1 оборот / 1.2s).
- Подключено: `--nv-accent` + мягкое свечение `box-shadow: 0 0 12px rgba(accent, .35)` — единственное свечение во всей системе, и оно означает факт: соединение живо.
- При `prefers-reduced-motion: reduce` вращения нет, состояние меняется сразу.
- Места применения: главная кнопка клиента, статус устройства в списках, индикатор в шапке панели.

Вся остальная система остаётся тихой: если у элемента нет повода светиться — он не светится.

## 8. Поставка и границы

- **Витрина:** `design/showcase.html` — самодостаточная страница: переключатель тем, свачи палитры обеих тем, шкала типографики, все компоненты §6 и интерактивное демо «кольца связи». Открывать через локальный сервер (`python -m http.server`), не через `file://` (шрифты и скрипты). Текст витрины и образцы копий компонентов — на русском, как и язык продукта по умолчанию (п. 4).
- **За границами:** иконография (набор выбирают циклы при сборке; требование — тонкий штрих 1.5px, совпадающий с весом кольца), иллюстрации, логотип.
- **Потребители:** цикл C (React-панель) и цикл E (клиенты) обязаны ссылаться на токены этого документа; любые новые цвета — только через изменение этого спека с пересчётом §7.
- **Проверка:** витрина прогнана в браузере (обе темы, вьюпорт 360px) — см. отчёт коммита.
