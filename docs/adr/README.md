# ADR

Здесь — решения, записанные полностью: контекст, отвергнутые альтернативы, последствия.

`0001`–`0003` и `0005`–`0008` пока существуют только как строки ADR-карты в
[спецификации цикла A](../superpowers/specs/2026-10-20-novavpn-cycle-a-access-core-design.md)
(раздел 14). Отдельный файл заводится тогда, когда у решения появляется измеренное
или внешнее обоснование, которое не помещается в строку таблицы — как у
[ADR-004](0004-wireguard-peer-apply.md), где основанием стал спайк S3.

| ADR | Файл | Статус |
|---|---|---|
| 004 | [0004-wireguard-peer-apply.md](0004-wireguard-peer-apply.md) | принят, подтверждён измерениями |

Не принятые молча: перед изменением любого ADR из этой папки сверяться с картой в
спецификации — она источник истины для остальных ADR.
